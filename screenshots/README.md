## 效果对比说明

| 效果类型 | 特征描述 | 推荐测试场景 |
|----------|----------|--------------|
| **模糊/锐化** | 细节增强或消散 | 砖墙、树叶、建筑纹理 |
| **边缘检测/浮雕** | 轮廓提取、立体感 | 建筑剪影、金属纹理 |
| **卡通着色** | 色块化、边缘描边 | 色彩鲜艳的物体 |
| **VHS/CRT** | 噪点、扫描线、色彩漂移 | 复古风格画面 |
| **万花筒/扭曲** | 对称图案、波纹 | 灯光、水面 |
| **Bloom/泛光** | 光晕效果 | 夜景灯光、太阳 |
