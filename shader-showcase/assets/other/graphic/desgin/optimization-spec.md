## 一、Part 1 重构：从 5 Stage 变为 4 模块三层结构

### 原结构问题
- Stage 1-4 与 Games101（数学/变换/光栅化/着色）和 LearnOpenGL（VAO/VBO/光照/延迟渲染）高度重叠
- Stage 5（Shader魔法/SDF）是本体系真正独有内容，却被放在最后
- 数学/管线作为独立 Stage 展开，读起来像教科书

### 新结构

```
Part 1: 基础入门 — 理论·实践·Shader思维

模块1: 空间变换
  ① [理论] 齐次坐标为何引入第4维 → MVP三步结论 → 左手系vs右手系（结论，不展开推导）
  ② [实践] GLM库 + VAO/VBO最小链路 + 旋转立方体代码
  ③ [Shader视点] fragCoord → 世界坐标逆变换：屏幕像素反算空间位置
  📎 games101 Lec 2-4 / learnopengl 入门-变换-坐标系-摄像机

模块2: 光照着色
  ① [理论] Phong/Blinn-Phong 三成分公式（给公式，一句话解释每项含义）
  ② [实践] Shadow Map 两步法 + PCF 最小实现代码
  ③ [Shader视点] ShaderToy中手写Blinn-Phong：一切计算发生在着色器
  📎 games101 Lec 7-8 / learnopengl 光照-阴影系列

模块3: 渲染架构
  ① [理论] FBO本质=离屏画布；延迟vs前向：GBuffer一次填、光照一次算
  ② [实践] 后处理管线（反相/灰度/边缘检测/模糊）最小代码
  ③ [Shader视点] 全屏三角形=滤镜：后处理的本质是把屏幕当纹理
  📎 games101 Lec 8 / learnopengl 高级OpenGL-帧缓冲-后处理

模块4: Shader思维 ★核心差异化★
  ① SDF：距离函数 → 等值面 → CSG（并/交/差/平滑混合）
  ② Ray Marching：屏幕像素发射射线 → SDF场景求交 → 法线重建 → 着色
  ③ 噪声家族：Value/Perlin/Simplex/Voronoi + fBm 一句话区分
  ④ 完整案例：纯ShaderToy Ray Marching 场景（金属球+玻璃球+软阴影）
  📎 本体系独有内容，games101/learnopengl 未覆盖
```

### 关键变化
| 旧 | 新 |
|---|---|
| Stage 1 数学热身独立成章 | 数学结论分散到各模块理论层，不单独成模块 |
| Stage 2 你好GPU独立成章 | VAO/VBO/Shader编译并入模块1实践层 |
| Stage 5 Shader魔法藏末尾 | 模块4 Shader思维前置，作为Part1压轴亮点 |
| 每条内容教科书式展开 | 每条三层结构：理论结论 + 关键代码 + Shader视点 |

## 二、Part 2-4 优化要点

### Part 2（高级渲染）— 收紧为四段式

每条 Case 统一格式：**动机一句 → 核心公式/伪代码 → 性能结论**

| 优化项 | 具体做法 |
|---|---|
| Cook-Torrance 三因子推导过长 | 只给结论公式+GLSL代码片段，推导留引用 |
| IBL 三件套 | 给组装顺序图，不展开每件的计算原理 |
| G-Buffer 布局展开过细 | 给 128bpp 一个典型布局，"变体参考[xx]" |
| 屏幕空间四效果各说各话 | 统一节拍：原理一句 + 伪代码 + 效果关键词 |
| GPU Driven 四子节无主次 | 加总起句："GPU Driven 本质=把CPU判断逻辑搬GPU Compute" |

### Part 3（商业级别）— 从百科全书到决策框架

| 优化项 | 具体做法 |
|---|---|
| 11 个引擎逐一介绍 | 改为一张多维对比表（Nanite/Lumen/GI方案/着色管线/TAA/RT/移动端/开源） |
| AAA 方案推测性叙述 | 砍掉"可能""预计"类语句，只保留已确认信息 |
| 移动端&Web 段落叙述 | 压缩为策略矩阵表 |

### Part 4（前沿发展）— 强化本体系判断

| 优化项 | 具体做法 |
|---|---|
| 各节结尾是介绍性总结 | 改为"本体系判断"：这个技术值不值得学、何时值得用 |
| NeRF 家族时间线过长 | 砍半，保留里程碑（NeRF→InstantNGP→3DGS） |
| 2030 年推测泛化 | 聚焦 3 条确定性趋势，去泛化预测 |
