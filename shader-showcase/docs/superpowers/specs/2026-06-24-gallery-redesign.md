# 场景大厅设计优化报告

> 日期：2026-06-24 | 目标：沉浸式、高质量 GPU 工具风格

---

## 一、诊断摘要

当前实现（`SceneGalleryScene.cpp`）存在 5 个核心问题：

| # | 问题 | 现状 | 影响 |
|---|------|------|------|
| 1 | **无背景视觉层次** | 纯色暗底 `(0.06,0.07,0.10)` | 平面感，无空间纵深 |
| 2 | **比例尺度粗糙** | 标题 4.5vh、卡片 12vh，无模数约束 | 松散、缺乏精致感 |
| 3 | **预览区空洞** | 纯色块 + 文字 "Preview" | 破坏沉浸，无法预览场景 |
| 4 | **零动画** | 全部瞬间切换 | 无响应感，粗糙 |
| 5 | **信息层级扁平** | 标题/描述/按钮视觉权重相同 | 视线无落脚点 |

---

## 二、优化总览

| 维度 | 优化前 | 优化后 |
|------|--------|--------|
| 布局 | Steam 库风格侧栏+列表 | **巨幕焦点式**：大 Hero + 玻璃质感侧栏 + 下方卡片 |
| 配色 | 纯暗色 `(0.06,0.07,0.10)` | 三层深度 + 蓝紫焦点色 + 环境光系统 |
| 动效 | 无 | Hover 缩放光晕 + 入场 Stagger + 点击物理反馈 |
| 字体 | ImGui 默认单字号 | 三级字阶：标题/副标题/正文比例化 |
| 边框 | 无或粗直边 | 微边框 `0.08a` + 圆角 `6px` |

## 四、布局重构（方案 A：巨幕焦点式）

```
┌────────────────────────────────────────────────────┐
│  ┌─ 环境光层 (径向渐变) ───────────────────────┐  │
│  │                                              │  │
│  │  🏷 Scene Gallery                             │  │
│  │                                              │  │
│  │  ┌──── Hero 区 (35vh) ──────────────────┐   │  │
│  │  │  场景名 — 场景描述                    │   │  │
│  │  │  [进入]                               │   │  │
│  │  └──────────────────────────────────────┘   │  │
│  │                                              │  │
│  │  [All] [Post-FX] [Particles]  ← 分类标签    │  │
│  │                                              │  │
│  │  ┌─ 卡片网格 (3列) ─────────────────────┐   │  │
│  │  │ [卡1]  [卡2]  [卡3]                  │   │  │
│  │  │ [卡4]  [卡5]  [卡6]                  │   │  │
│  │  └──────────────────────────────────────┘   │  │
│  │                                              │  │
│  └──────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────┘
```

### 4.1 区域划分

| 区域 | 高度 | 说明 |
|------|------|------|
| 顶栏 | `h * 0.06` | 标题 "Scene Gallery" + 副标题 |
| Hero | `h * 0.28` | 选中场景大卡片，背景光晕 |
| 分类标签 | `h * 0.04` | 横向标签条，取代原侧边栏 |
| 卡片网格 | 剩余空间 | 3 列网格，支持滚动 |

### 4.2 卡片规格

```
卡片宽 = (w - padding) / 3
卡片高 = 卡片宽 * 0.75
缩略图 = 卡片高 * 0.6
标题字号 = h * 0.022
描述字号 = h * 0.016
```

### 4.3 侧边栏去除理由

- 场景数预期 < 20，分类标签更紧凑
- 横向标签释放 220px 横向空间给 Hero 和卡片
- 视觉上更接近 XGPU / PS5 体验

## 五、动效系统

### 5.1 Hover 微交互

```
时长: 200ms ease-out
变换: scale(1.02) + 边框 alpha 0.04→0.2 + 阴影增强
实现: 每帧 lerp 插值当前 scale/borderAlpha/shadowAlpha
```

数据结构：
```cpp
struct CardAnimState {
    float hoverT = 0.0f;      // 0→1 over 200ms
    float entryT = 0.0f;      // 0→1 over 400ms + delay
    float clickScale = 1.0f;  // 1.0→0.97 on click, spring back
};
std::vector<CardAnimState> m_cardAnims;
```

### 5.2 入场 Stagger

```
卡片 N 入场: delay = N * 80ms, duration = 400ms
从: opacity 0, translateY(20px)
到: opacity 1, translateY(0)
```

### 5.3 点击反馈

```
按下: scale(0.97) over 100ms
释放: scale(1.0) spring-back 200ms
进入场景: 全屏暗色覆盖 fadeIn 300ms → 切换
```

### 5.4 分类切换动画

```
crossfade: 旧卡片组淡出 200ms + 新卡片组 stagger 入场
```

## 七、实现计划

### 7.1 文件改动

| 文件 | 操作 | 说明 |
|------|------|------|
| `SceneGalleryScene.h` | 修改 | 添加动画状态结构体、新布局参数 |
| `SceneGalleryScene.cpp` | 重写 | 全量替换布局、配色、动画逻辑 |
| `SceneEntry` (Registry) | 修改 | 新增 `thumbTexture` 字段（可选） |
| `main.cpp` | 修改 | 注册时提供缩略图路径 |

### 7.2 实现顺序

1. **配色替换** — 将所有 `IM_COL32` 常量更新为新色值
2. **布局重构** — 侧栏 → 顶部标签，卡片列表 → 3 列网格
3. **Hero 区** — 选中场景大预览卡片
4. **动效** — Hover lerp + 入场 stagger
5. **缩略图** — 从 assets 加载真实截图

## 八、性能约束

- ImDrawList 自绘，不增加 ImGui 控件开销
- 动画仅 4 个 float/卡，< 1KB 状态
- 环境光用 2-4 个大的 `AddRectFilled` + 渐变模拟
- 总 GPU 开销增加 < 0.1ms（纯 2D 绘制）
