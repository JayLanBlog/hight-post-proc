# 设计文档：FPS性能显示 + 后端切换 + 原图对比

**日期**: 2025-05-30  
**作者**: AI Assistant  
**状态**: 已确认，待实现

---

## 1. 背景与目标

基于用户反馈，需要优化 Shader Showcase 应用的以下功能：

1. **后端切换可视化**：当前仅支持 `Ctrl+1`/`Ctrl+2` 快捷键切换 OpenGL/Vulkan，无 UI 入口
2. **FPS 性能显示**：当前 FPS 仅在 CoverFlowScene 副标题中显示，详情页无 FPS
3. **原图/效果图对比**：已有对比模式（C 键）但默认关闭且有黑屏 bug，需要重新设计

---

## 2. 设计方案

### 2.1 功能一：后端切换 + FPS 显示

**选择方案**: B - 右上角浮动面板

#### 设计描述

在窗口右上角添加一个半透明浮动面板，包含：

- **后端切换按钮**: OpenGL / Vulkan 两个按钮，当前激活后端高亮显示
- **FPS 显示**: 大号绿色字体显示当前帧率
- **后端信息**: 小字显示当前后端版本（如 "OpenGL 4.6 (SPIR-V)"）

#### 视觉规格

```
┌─────────────────────────────────────────┐
│  Shader Showcase                    ┌───┐│
│                                     │GL ││  ← OpenGL 按钮 (激活状态)
│                                     │VK ││  ← Vulkan 按钮 (未激活)
│                                     │60 ││  ← FPS 显示 (绿色)
│                                     │4.6││  ← 版本信息
│                                     └───┘│
│                                         │
│         [主内容区域]                     │
│                                         │
└─────────────────────────────────────────┘
```

- 面板位置: 窗口右上角，距边缘 8px
- 面板样式: 半透明黑色背景 (`rgba(0,0,0,0.75)`)，圆角 6px
- 按钮样式: 激活状态 `#444`，未激活状态 `#333` + 透明度 0.6
- FPS 颜色: `#4f4` (亮绿色)
- 版本信息: `#888` (灰色小字)

#### 交互行为

- 点击后端按钮触发 `Application::SwitchBackend()`
- 切换时面板短暂闪烁提示
- FPS 实时更新（每帧计算，每秒刷新显示）

### 2.2 功能二：详情页原图/效果图对比

**选择方案**: B - 滑动对比（Before/After）

#### 设计描述

详情页默认进入对比模式，使用单张图片叠加 + 可拖拽竖线分割：

- **左侧区域**: 显示原图（Before）
- **右侧区域**: 显示效果图（After）
- **分割竖线**: 可水平拖拽，实时调整左右区域比例
- **拖拽手柄**: 竖线中央圆形按钮，带左右箭头图标

#### 视觉规格

```
┌─────────────────────────────────────────┐
│  [原图区域]        │         [效果图区域] │
│                    │                     │
│                    │                     │
│     Before         │        After        │
│                    │                     │
│                    │                     │
│                    │                     │
│         ━━━━━━━━━━━●━━━━━━━━━━━          │  ← 可拖拽分割线
│                    │                     │
│                    │                     │
└─────────────────────────────────────────┘
```

- 默认分割位置: 50%（居中）
- 分割线样式: 3px 宽，亮蓝色 `#4af`
- 拖拽手柄: 28px 圆形，蓝色背景，白色 `⟺` 图标
- 区域标签: 半透明文字 "原图"/"效果图" 显示在各自区域中央

#### 交互行为

- 鼠标悬停分割线时显示拖拽光标
- 拖拽时实时更新分割位置
- 按 `C` 键切换到全屏效果图模式（隐藏对比）
- 再次按 `C` 键返回对比模式

## 3. 技术实现要点

### 3.1 后端切换 + FPS 面板

**新增文件**: `src/ui/PerformancePanel.h`, `src/ui/PerformancePanel.cpp`

**核心逻辑**:
- 在 `Application::OnImGui()` 中全局渲染（主页面和详情页都可见）
- 使用 `Application::GetBackendType()` 获取当前后端
- 使用 `ImGui::GetIO().Framerate` 获取 FPS
- 调用 `Application::SwitchBackend()` 切换后端

**依赖**:
- `Application.h` - 获取后端类型和切换接口
- `IRenderBackend.h` - 获取后端版本信息

### 3.2 滑动对比视图

**修改文件**: `src/app/EffectDetailScene.cpp`

**核心逻辑**:
- 在 `OnRender()` 中先渲染效果图到 `m_effectTex` FBO
- 在 `OnImGui()` 中使用 `ImGui::Image()` 显示原图作为底层
- 使用 `ImDrawList` 裁剪右侧区域显示效果图
- 分割线位置存储在 `m_compareSplit` (0.0 ~ 1.0)

**渲染流程**:
1. 渲染全屏效果图到 FBO 纹理
2. ImGui 窗口：底层显示原图
3. 根据 `m_compareSplit` 计算分割线 X 坐标
4. 在分割线右侧绘制效果图（使用 `ImDrawList->AddImage` 带裁剪）
5. 绘制分割线和拖拽手柄

**交互处理**:
- 检测鼠标在分割线附近的悬停
- 拖拽时更新 `m_compareSplit`
- 限制范围 0.1 ~ 0.9（避免完全遮住某一侧）

## 4. 边界情况处理

| 场景 | 处理方案 |
|------|----------|
| Vulkan 未编译 | 后端按钮禁用，显示 "Vulkan (未启用)" |
| 切换后端失败 | 显示错误提示，回退到 OpenGL |
| 效果图渲染失败 | 对比模式自动禁用，显示错误信息 |
| 窗口尺寸变化 | 分割线位置保持相对比例 |
